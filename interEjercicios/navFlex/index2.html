El Flex

El modelo de caja flexible, conocido como Flexbox, es un modelo de diseño en CSS que permite distribuir el espacio entre los elementos de una interfaz y alinear estos elementos de manera eficiente, incluso cuando su tamaño es desconocido o dinámico. Flexbox está diseñado para mejorar la capacidad de los contenedores y sus elementos hijos, facilitando la creación de diseños complejos y adaptativos sin necesidad de utilizar flotaciones o posicionamientos complicados.
